# 字段定义 boothplan

只写"这个字段是什么意思、怎么算、什么单位"。判定逻辑见 `docs/DEPTH.md`。

## 1 名录字段

| 字段 | 页面列名 | 类型 | 单位 | 可空 | 含义与计算方式 |
|---|---|---|---|:--:|---|
| `exhibitor_name` | 展商名称 | string | — | 否 | 去首尾空格、全角转半角；空值哨兵视为缺失 |
| `booth_raw` | 展位号 | string | — | 否 | 门户原写法，保留原样以便回源核对 |
| `booth_code` | 归一展位号 | string | — | 是 | `馆-排-位`，排/位两位补零，如 `A1-03-05` |
| `hall_raw` | 展馆 | string | — | 是 | 与展位号里的馆号交叉校验，冲突即隔离 |
| `area_sqm` | 展位面积 | decimal | ㎡ | 是 | 去千分位与单位后缀后取 1 位小数；哨兵为 null，不是 0 |
| `visit_priority` | 拜访优先级 | int | — | 是 | 1 最高；空值按 5 处理，不参与任何合计 |
| `owner` | 对接人 | string | — | 是 | 只做显示 |
| `note` | 备注 | string | — | 是 | 含空位说明与全角写法说明 |

## 2 展位号语法

| 写法 | 含义 | 归一结果 |
|---|---|---|
| `A1-3-05` | 馆-排-位 | `A1-03-05` |
| `B2-12` | 馆-位（单排馆，排固定 01） | `B2-01-12` |
| `A-01` | 馆-位，单字母馆归到 1 号子馆 | `A1-01-01` |
| `C3` | 馆 + 位 | `C1-01-03` |
| `3x3` / `3×3` | 面积型光地，没有网格坐标 | 无 `booth_code`，状态 `unplaced` |
| 其它 | 无法解析 | 隔离，原因码 `Q_BOOTH_UNPARSABLE` |

排/位一律字符串，保留前导零：`A-01` 的位号是 `"01"` 而不是 `1`。

## 3 平面坐标与距离

- 馆锚点 = 该馆「1 排 1 位」的地面坐标（米），见 `app/config.py` 的 `HALLS`。
- 位向 x 正方向，间距 8 米；排向 y 正方向，间距 6 米。
  `x = 锚点x + (位 - 1) × 8`，`y = 锚点y + (排 - 1) × 6`。
- 两点距离：同馆取直线距离；跨馆在直线距离上另加 150 米通道折算。
- 一律 Decimal，量化到 0.1 米；合计按分段逐项相加后再量化，不用 float 累加。
- 步行时间：`距离 ÷ 72 米/分`，向上取整到整分钟。

## 4 时间与时间窗

- 入库一律 UTC（ISO 8601 带偏移），展示按 `Asia/Shanghai (+08:00)`。
- 缺偏移的写法按 `+08:00` 解释，并留一条 `T_NAIVE_TIME` 记录。
- 论坛时间窗为**左闭右开** `[start, end)`：端点相接不算冲突，重叠 1 分钟即冲突。
- 展期与开放时间（本地分钟数）：
  - 第 1 天 2026-11-16：`[540, 1050)` 即 09:00–17:30
  - 第 2 天 2026-11-17：`[540, 960)` 即 09:00–16:00
- 时间窗必须整体落在开放时间内且两端同一天，否则 `T_OUTSIDE_HOURS`。

## 5 排程字段

| 字段 | 类型 | 单位 | 含义 |
|---|---|---|---|
| `candidates` | int | 个 | 候选站点 = 可排程展商 + 无冲突的固定论坛场次 |
| `scheduled` | int | 个 | 排入：落位且在首选时段内（优先级 3 及以后不看首选） |
| `rescheduled` | int | 个 | 改期：落位但不在首选时段 |
| `conflict` | int | 个 | 冲突：时间窗越界或与固定窗重叠 |
| `skipped` | int | 个 | 跳过：没有坐标、当天排满、同名冲突 |
| `dwell` | int | 分 | 停留：展商 20 分，论坛 35 分 |
| `walk_m` | decimal | 米 | 该点位相对上一个点位的步行距离，1 位小数 |
| `walk_total_m` | decimal | 米 | 已排点位分段之和，1 位小数 |
| `slack` | int | 分 | 收工到闭馆还剩多少分钟 |

首选时段：优先级 1 → 10:00–12:00，优先级 2 → 13:00–15:00，其余不限。

## 6 空值与空态

- `null`（哨兵）：`-`、`--`、`/`、`N/A`、`未知`、`无`、`暂无`、`待定` 等，见
  `app/config.py` 的 `SENTINELS`。
- `""`（空串）：与哨兵同义，按 null 处理，不参与任何合计。
- `0`（真值）：只有真实测量到 0 才写 0，哨兵一律 null。
- 空态三态分开：
  - 0 页：`S_PAGE_MISSING`，批次失败，页面给空态一句；
  - 仅表头：阶段 `out_count = 0`，批次仍算完成，行程单为空；
  - 全空行：按列数校验逐行隔离，`Q_COLUMN_COUNT` 计数。

## 7 去重键

- 展商去重键：`exhibitor_name` 归一（去空白、括号统一、英文小写）+ 展位号。
  选择理由：同一家公司在两个馆各有一个展位是真实情况，用名称单键会误合并。
- 同名但不同馆：判 `Q_DUP_EXHIBITOR`，保留首次出现，两条都写证据行。
- 展位号被两家占用：判 `Q_DUP_BOOTH`（提示级），两条都保留，人工确认是否合展。

## 8 原因码级别

| 级别 | 含义 | 是否阻止进行程单 |
|---|---|:--:|
| `error` | 已隔离，该行不参与排程 | 是 |
| `warn` | 保留但需人工看一眼 | 否 |
| `info` | 只是记录（编码回退、重复表头） | 否 |

## 9 输入摘要与版本

- `input_digest` = 每页 `url|sha256` 按出现顺序拼接后的 sha256，64 位十六进制。
- `batch_key` = `来源:input_digest 前 16 位`；同一键重跑复用已完成批次。
- `version` 在同一 `batch_key` 内递增；提交版本小于当前最新版本时拒绝（409）。

## 10 备选方案字段（M7）

| 字段 | 页面列名 | 类型 | 单位 | 含义与计算方式 |
|---|---|---|---|---|
| `weight` | 权重 | int | — | 优先级 1→5、2→4、3→3、4→2、5→1；固定论坛窗记 0，不可放弃 |
| `transfer_min` | 换乘(分) | int | 分 | 跨馆换乘 4 分，同馆与入口记 0；已并入到站时刻 |
| `switches` | 跨馆 | int | 次 | 一天内相邻两点馆号不同的次数 |
| `cap` | 跨馆上限 | int | 次/天 | 接口参数，取值 1–12，默认 6 |
| `two_opt` | 2-opt 反向移动 | int | 次 | 反转区间后更短且仍可行的接受次数 |
| `delta_stops` | 站点差 | int | 个 | 备选 − 主方案，负数表示少排 |
| `delta_weight` | 权重差 | int | — | 备选 − 主方案的排入权重合计 |
| `delta_walk_m` | 步行差 | decimal | 米 | 备选 − 主方案的步行合计，1 位小数 |
| `delta_switches` | 跨馆差 | int | 次 | 备选 − 主方案的跨馆次数合计 |

三套方案共用同一批候选，只是取舍规则不同：

- A 主方案：按 M4 顺序插入，跨馆不限；
- B 减站换权重：对没排进去的重权重点位，放弃低权重站点腾时段，只在更重时接受；
- C 限跨馆：按馆聚类插入，守住每天跨馆次数上限。

权重账：排入权重 + 未排入权重 = 候选权重合计，三套各自成立。

方向距离：`walk_m` 按顺序逐段相加。A2→B2 走二层连廊，B2→A2 要下一层绕行，
回程多 60 米，所以往返不相等；全馆两两核验的结果在 `/alternate` 的核验表里。
